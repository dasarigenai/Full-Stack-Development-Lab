\# Full Stack Development



This repository contains the programs and practical experiments completed as part of my Full Stack Development Lab.



\## 📌 About the Repository



The purpose of this repository is to practice and understand full-stack web development concepts through hands-on experiments using JavaScript, Node.js, Express.js, MongoDB, React, and related technologies.



\## 🛠️ Technologies Used



\- HTML

\- CSS

\- JavaScript

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- React.js

\- EJS

\- Docker



\## 📂 Experiments Covered



\### 1. Node.js

\- File System Operations

\- Asynchronous File Operations

\- CRUD Operations using Arrays

\- Manual Routing

\- URL Handling



\### 2. Express.js

\- Basic Express Server

\- Middleware

\- File Persistence

\- Non-Persistent Data Handling

\- JSON Server

\- Template Engine using EJS



\### 3. MongoDB and Mongoose

\- MongoDB with Express

\- Mongoose with Express

\- MVC Architecture

\- Authentication and Todo Application



\### 4. React.js

\- HTML Rendering

\- JSX Rendering

\- Multiple Components

\- State and Events

\- Conditional Rendering

\- Rendering Lists

\- Forms and Events

\- React Router

\- Frontend CRUD Application



\### 5. MERN Stack

\- MERN CRUD Application



\### 6. Docker

\- Docker Commands

\- Docker Notes



\## 🚀 How to Run



1\. Clone this repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/dasarigenai/Full-Stack-Development-Lab.git

&#x20;  ```



2\. Open the required experiment folder.



3\. Install dependencies if the folder contains a `package.json` file:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



4\. Run the application using the script specified in that folder's `package.json`.
